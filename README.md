# ☕ Java Programming Practice

A structured collection of Java programs covering core concepts - organized by topic for easy navigation and learning reference.

---

## 📁 Repository Structure

```plaintext
java-programming-practice/
├── arrays/         # Array manipulation and operations
├── basics/         # Java fundamentals and syntax
├── numbers/        # Number-based logic and math programs
├── patterns/       # Pattern printing programs
├── recursion/      # Recursive problem solving
├── strings/        # String manipulation and operations
└── README.md
```

---

## 📚 Topics Covered

| Topic | Description |
|-------|-------------|
| Basics | Variables, data types, loops, conditionals |
| Arrays | 1D/2D arrays, searching, sorting |
| Strings | String methods, manipulation, palindrome etc. |
| Numbers | Prime, factorial, fibonacci, Armstrong etc. |
| Patterns | Star, number & character pattern programs |
| Recursion | Factorial, fibonacci, tower of hanoi etc. |

## 🚀 How to Run

1. Clone the repository:
```bash
   git clone https://github.com/giri89/java-programming-practice.git
```
2. Open in **IntelliJ IDEA** or **Eclipse**
3. Navigate to any topic folder
4. Run the desired `.java` file
